# Exercício Cypress - Agenda de Contatos

Projeto desenvolvido como parte do curso da EBAC para praticar testes end-to-end (E2E) utilizando o [Cypress](https://www.cypress.io/).

## 🎯 Objetivo
Automatizar testes na aplicação [EBAC Agenda de Contatos](https://ebac-agenda-contatos-tan.vercel.app/), validando as funcionalidades de:
- Inclusão de um contato
- Alteração de um contato
- Remoção de um contato

## 🛠 Tecnologias utilizadas
- [Node.js](https://nodejs.org/)
- [Cypress](https://www.cypress.io/)
- JavaScript

## 📂 Estrutura do projeto
```

📦 exercicio\_cypress-\_agenda
┣ 📂 cypress
┃ ┣ 📂 e2e          # Scripts de teste
┃ ┣ 📂 fixtures     # Dados estáticos para testes
┃ ┣ 📂 support      # Comandos e configuração global
┣ 📜 cypress.config.js
┣ 📜 package.json
┗ 📜 README.md

````

## 🚀 Como rodar o projeto

1. **Instale as dependências**

   ```bash
   npm install
   ```

2
. **Execute os testes**

   * Modo interativo:

     ```bash
     npx cypress open
     ```
   * Modo headless (terminal):

     ```bash
     npx cypress run
     ```
